# configs

3D Gaussian Splatting の学習実験におけるハイパーパラメータを管理するディレクトリ。

## ディレクトリ構成

```
configs/
├── default/       # デフォルトのハイパーパラメータ（基準値）
│   └── gs.json
└── experiment/    # 実験用のハイパーパラメータ（実験ごとに変更）
    └── gs.json
```

## 運用方針

### default/

- 学習に用いるハイパーパラメータの **基準値** を保持する
- 実験ごとに変更することはなく、基準自体を見直す必要が生じた場合にのみ更新する
- **Git の追跡対象** — 基準値の変更は重要な意思決定であるため、変更履歴を残す

### experiment/

- 実験開始時に `default/` から config ファイルをコピーし、ハイパーパラメータを変更して使用する
- 初期状態ではファイルを配置しない（実験のたびに `default/` からコピーする運用）
- 実験のたびに頻繁に書き換えるため、**Git の追跡対象外** とする
- 実験時に実際に参照されるのはこちらの config ファイル

### ログとの連携

実験実行時に `default/` と `experiment/` の差分をログに記録することで、各実験でどのパラメータを変更したかを追跡可能にする。
