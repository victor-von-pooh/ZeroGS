# configs/experiment

実験用のハイパーパラメータを管理するディレクトリ。

## 概要

- 実験開始時に `default/` から config ファイルをコピーし、ハイパーパラメータを変更して使用する
- 初期状態ではファイルを配置しない（実験のたびに `default/` からコピーする運用）
- 学習時に実際に参照されるのはこのディレクトリ内の config ファイル
- `default/` との差分がログに記録されるため、各実験での変更内容を後から確認できる

## Git 管理

- **追跡対象外** — 実験のたびに頻繁に変更するため、Git では管理しない

## 使い方

```bash
# default/ から config をコピー
cp ../default/gs.json .

# コピーした gs.json のハイパーパラメータを編集して実験を実行
```
