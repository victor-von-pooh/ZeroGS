# paper

ZeroGS の実装・設計の参考にした論文（arXiv PDF）を配置するディレクトリ。

## 趣旨

3DGS および関連手法の論文を手元に置いておき、実装中に参照できるようにする。今後、関連する論文が増えた場合はこのディレクトリに追加していく。

## 配置済みの論文

```
paper/
├── 2308.04079v1.pdf  # arXiv:2308.04079
└── 2605.15760v1.pdf  # arXiv:2605.15760
```

各 PDF はファイル名の arXiv ID から `https://arxiv.org/abs/<id>` で原典を参照できる。

## Git 管理

- **追跡対象** — 参考論文として常に手元で参照できるよう、PDF も Git で管理する
